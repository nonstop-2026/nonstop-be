### 검색 구현 주의 사항

- Firestore Standard 에디션은 전문 검색을 지원하지 않고 접두어 검색만 가능하다. FR-05-01을 Firestore 기본 쿼리만으로 구현하지 않는다.
- 후보는 Firestore Enterprise 에디션의 전문 검색(프리뷰 상태)과 외부 검색 엔진(Typesense, Algolia 등)이다. 두 후보 모두 무료 조건에서의 사용 가능 여부가 확인되지 않았다.

### 웹 푸시 발송 주의 사항 (데모 범위 외)

- iOS Safari에서는 사용자가 사이트를 홈 화면에 추가한 경우에만 웹 푸시를 받을 수 있다. 발송 실패나 미수신이 있을 수 있음을 전제로 설계한다.
- 만료되거나 무효한 푸시 토큰은 발송 응답을 보고 정리한다.

## 구현 정책

P-02, P-07은 결번이다. 이 번호에 해당하는 내용은 현재 없다.

### P-01 콘텐츠 수집

- arXiv 카테고리 화이트리스트(`cs.AI`, `cs.CL`, `cs.CV`, `cs.HC`, `cs.SE`)로 한정한다. 1차 타깃인 IT 관련 분야 학부생과 대학원생 기준이다.
- 온보딩 키워드는 고정 목록이며, 미리 정한 영문 슬러그를 문서 ID로 쓴다.
- 데모에서는 수동 백필 1회, 카테고리별 일일 상한 건수를 둔다.
- 순차 호출과 지수 백오프를 적용하고, 대량 수집 시 OAI-PMH 전환을 검토한다.
- 철회된 논문은 카드를 비활성화하고, 개정판은 재생성 큐에 넣은 뒤 안내 배지용 상태값을 내려준다.
- arXiv API 약관(2026-11-07 확인): 요청은 3초에 1회 이하, 동시 연결 1개이며 모든 기기를 합산해 적용한다. 값은 `ARXIV_REQUEST_INTERVAL_SECONDS`로 분리한다. e-print를 자체 서버에서 저장·제공하지 않고, arXiv의 보증을 받은 것처럼 표현하지 않으며, 원문은 초록 페이지로 연결한다. 약관은 바뀔 수 있으므로 관련 코드를 고치기 전에 다시 확인한다.

### P-03 AI 생성물

- 생성 결과를 표본 검수하고, 오류가 확인되면 즉시 비노출 처리한 뒤 재생성한다.
- 카드 필드는 JSON 스키마 기반 구조화 출력으로 받아 파싱 실패를 줄인다.
- 챗봇은 논문 범위 밖 질문, 의료 · 법률 · 투자 조언, 개인정보 요구에 응답하지 않는다.

### P-04 개인정보

- 회원 가입을 받지 않고 이용자 식별 정보를 수집하지 않는다.
- 관심 키워드, 저장 목록, 출석 기록은 브라우저에만 저장한다.
- 호스팅 서비스가 남기는 접속 기록(IP 주소 등)은 운영자가 이용자 식별에 쓰지 않는다.
- 로그에 요청 파라미터의 관심 키워드를 남기지 않는다.

### P-05 알림 (데모 범위 외)

- 일 1회, 사용자 지정 시간, 기본값 오전 9시
- 정보성과 광고성 알림을 구분하고, 광고성은 별도 수신 동의와 야간 발송 제한을 적용한다.
- 리인게이지먼트 알림은 주 1회가 상한이고, 3회 연속 미반응 시 중단한다.

### P-06 운영 및 장애

- 배치 실패 시 전일 콘텐츠를 유지하고, 홈 응답에 갱신 지연 상태값을 내려준다. (데모 범위 외: 데모는 수동 백필)
- Gemini 호출 실패는 2회 재시도 후 실패 큐로 보내고, 24시간 안에 해결되지 않으면 당일 노출에서 제외한다.
- 논문당 1회 호출로 3개 수준을 동시에 생성하고, 개정판 재생성은 데모 범위 외다.
- 챗봇에는 사용자당 일일 질문 상한과 컨텍스트 길이 상한을 적용한다. (데모 범위 외)

## 릴리스 계획

0. **데모 (2026-11-08 ~ 11-30):** 온보딩, 홈, 피드, 상세, 저장함, 출석 스트릭. 로그인과 알림 없음
1. **1차 (MVP):** 온보딩, 홈, 피드, 상세, 저장함, 알림
2. **2차:** 검색 고도화, 폴더, 오프라인 캐시 지원
3. **3차:** 챗봇 품질 개선, 추천 알고리즘 고도화

챗봇은 Gemini 호출 비용과 응답 품질 이슈가 초기 리텐션 측정을 흐리지 않도록 일부러 1차에서 뺐다.
